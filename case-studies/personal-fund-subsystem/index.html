Healthcare

Personal Fund Subsystem

A browser workspace for hospitals that hold money on behalf of patients—lookup, post transactions, run reports, and keep NCFS codes in sync.

Blazor .NET 8 SQL Server SSRS Healthcare finance
Explore the product Download case study
3 .NET projects (client, API, shared)
12+ SSRS operational reports
1 Ledger—rules stay in SQL Server
Challenge

Legacy rules, modern UI

Every deposit must hit the right MRN and institution. The database already held the rules—staff needed a permissioned web workspace.

Solution

Blazor on proven SQL

Blazor Server, ASP.NET Core API, and Dapper over stored procedures—with Windows sign-in and SSRS for the reports finance trusts.

Outcome

Live operations platform

Accounts, grouped posting, inquiry, allowances, bulk interest, and audit-ready reports—without rewriting the ledger.

Architecture

Web UI on top of a proven data layer

New work sits in identity, permissions, and UX; posting and balances remain in SQL Server procedures.

  • Blazor Server + Radzen for responsive ops screens
  • API enforces the same permissions as the menu (403 if bypassed)
  • SSRS delivers HTML, PDF, and Excel in a tabbed report workspace
