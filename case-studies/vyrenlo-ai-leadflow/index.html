Challenge

Leads arrive everywhere

Inbound sits in inboxes and forms. Follow-ups slip. Teams lack one prioritized view—and hot opportunities go cold waiting for a first reply.

Solution

API as brain, n8n as hands

FastAPI owns tenants, qualification, dedup, and approvals. n8n schedules follow-ups and connects social ingest—without redeploying application code.

Outcome

Sales-demo-ready MVP

Docker stack, CI tests, seed data, and a twelve-minute demo: web form → AI score → staff alert → follow-up → engaged reply—with humans in the loop.

Architecture

One API, many tenants, orchestration outside the monolith

PostgreSQL is source of truth; Redis rate-limits public ingest; OpenAI returns validated JSON; n8n handles cron, webhooks, and channel glue.

  • Row-level tenant_id isolation on every owned record—cross-tenant IDs return 404 in tests
  • HMAC webhooks to n8n; service-token auth on internal automation calls
  • Vertical templates seed prompts, follow-up intervals, and channel defaults at provision time

Design lessons

What we would ship again on the next automation product

  • Keep qualification, dedup, consent, and approvals in the API—n8n schedules and connects systems
  • Ship multi-tenant schema and RBAC early; retrofitting isolation is expensive
  • Pydantic-validated LLM JSON beats brittle parsing and simplifies tests
  • require_approval_for_outbound makes automation palatable for brand-sensitive clients
  • Vertical JSON templates position one codebase for real estate, B2B, and agency use cases
  • Mailpit, seed scripts, and a scripted demo make the portfolio story repeatable
