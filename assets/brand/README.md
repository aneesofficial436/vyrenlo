# Vyrenlo brand assets (LinkedIn)

Matches site colors: `#05060A` background, gradient `#6EE7FF` → `#A78BFA` → `#F472B6`.

## LinkedIn upload sizes

| File | Use on LinkedIn |
| --- | --- |
| `linkedin-logo-400.png` | **Company page logo** (400×400) |
| `linkedin-company-cover.png` | **Company page cover** (1128×191) |
| `linkedin-profile-cover.png` | **Personal profile background** (1584×396) |

SVG sources are in this folder if you need to edit in Figma/Inkscape.

## Generate PNGs

From project root:

```bash
npm install sharp
node assets/brand/export-png.mjs
```

Or open any `.svg` in Chrome → zoom to fit → screenshot, or use [CloudConvert](https://cloudconvert.com/svg-to-png) at the sizes above.
